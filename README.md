# Wanderlust — Full Stack Property Listing Web Application

A full-stack property listing web application developed using Node.js, Express.js, MongoDB, and EJS. Wanderlust allows users to explore properties, manage listings, and share reviews.

This project was built as part of my full-stack web development training at Apna College (Delta 9.0). I independently extended the original project by implementing search and category filtering to improve property discovery.

## Live Demo

[Visit Wanderlust](https://wanderlust-fullstack-7ypq.onrender.com/listings)

## Features

### Property Listings
- Browse available properties with images, descriptions, and prices.
- View detailed information about individual listings.
- Create, edit, and delete listings, subject to authorization.

### Search — Independently Implemented
- Search for properties using the application's search functionality.
- Find relevant listings without manually browsing every property.

### Category Filtering — Independently Implemented
- Explore listings by category.
- Filter available properties to find relevant accommodation.

### User Authentication
- Register and log in to an account.
- Access protected actions based on authentication and authorization.

### Reviews and Ratings
- View reviews and ratings for properties.
- Submit reviews through the application's review functionality.

## Running Locally

### Prerequisites

- Node.js and npm
- MongoDB or a MongoDB Atlas database
- Required environment variables for your application

### Installation

1. Clone this repository.
2. Open the project directory.
3. Install dependencies:

```bash
npm install
```

4. Configure the environment variables required by the project.
5. Start the application using the command defined in `package.json`.
6. Open the local address displayed in your terminal.

**Security:** Never commit your real `.env` file, database credentials, or API secrets.
